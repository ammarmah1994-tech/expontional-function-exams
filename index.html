المسألة 5 (دورة 2024 الأولى):

  • 2) عيّن الحل الخاص f للمعادلة (E) الذي يحقق الشرط الابتدائي: f(0) = 1.

سلم الحل:

المسألة 8:
عيّن تابعاً كثير حدود من الدرجة الثانية f(x) = ax² + bx + c بحيث يكون حلاً للمعادلة التفاضلية الآتية:[span_38](start_span)[span_38](end_span)
-y + 2y' = x² + 3
[span_39](start_span)[span_39](end_span)

سلم الحل:

مشتق التابع هو y' = 2ax + b. بالتعويض في المعادلة التفاضلية:[span_40](start_span)[span_40](end_span)
-(ax² + bx + c) + 2(2ax + b) = x² + 3
-ax² + (4a - b)x + (2b - c) = x² + 3
بمطابقة المعاملات نجد:
-a = 1 ==> a = -1
4(-1) - b = 0 ==> b = -4
2(-4) - c = 3 ==> -8 - c = 3 ==> c = -11
التابع المطلوب: f(x) = -x² - 4x - 11.

سلم الحل:
