أولاً: مسائل المعادلات التفاضلية التحريرية (تشمل دورة 2024 الأولى)

أسئلة تحريرية دقيقة
المسألة 1 (مسألة دورة 2024 الأولى - المرتبة الأولى): امتحان دورة 2024 - الأولى
لتكن لدينا المعادلة التفاضلية الخطية الآتية:
$$(E): \quad y' - 2y = 0$$
  • 1) أوجد الحل العام للمعادلة التفاضلية $(E)$ على المجموعة $\mathbb{R}$.
  • 2) عيّن الحل الخاص $f$ للمعادلة $(E)$ الذي يحقق الشرط الابتدائي: $f(0) = 1$.
  • 3) احسب قيمة التكامل التحريري الآتي للتابع الناتج: $$I = \int_{0}^{\ln 2} f(x) \, dx$$
خطوات الحل التحريري مخصصة لورقة الإجابة 60 درجة

سلم وتفاصيل الحل التحريري النموذجي:

1) الحل العام: المعادلة من الشكل $y' = ay$ حيث $a = 2$.
الحل العام يُعطى بالقاعدة: $$y = C \cdot e^{2x} \quad (C \in \mathbb{R})$$
2) تعيين الحل الخاص: نعوض الشرط الابتدائي $f(0) = 1$:
$$1 = C \cdot e^{2(0)} = C \implies C = 1$$ إذن الحل الخاص هو التابع: $$f(x) = e^{2x}$$
3) حساب التكامل: $$I = \int_{0}^{\ln 2} e^{2x} \, dx = \left[ \frac{1}{2} e^{2x} \right]_{0}^{\ln 2} = \frac{1}{2} \left( e^{2 \ln 2} - e^0 \right)$$ بما أن $e^{2\ln 2} = e^{\ln(4)} = 4$، يكون: $$I = \frac{1}{2} (4 - 1) = \frac{3}{2}$$
المسألة 2 (المسألة رقم 10 في الاختبار): معادلة خطية بوجود ثابت
حل المعادلة التفاضلية الآتية:[span_0](start_span)[span_0](end_span)
$$y' - 2y = -6$$[span_1](start_span)[span_1](end_span)
علماً أن المخطط البياني للحل يمر بالنقطة $A(\ln 2, -5)$.[span_2](start_span)[span_2](end_span)
أوجد الحل العام ثم عوّض إحداثيات النقطة $A$ 40 درجة

سلم الحل التحريري:

المعادلة من الشكل $y' = ay + b$ مع $a = 2$ و $b = -6$.
الحل العام هو: $$y = C e^{ax} - \frac{b}{a} = C e^{2x} - \frac{-6}{2} = C e^{2x} + 3 \quad (C \in \mathbb{R})$$
بما أن الخط البياني يمر بالنقطة $A(\ln 2, -5)$[span_3](start_span)[span_3](end_span)، فإن $y(\ln 2) = -5$: $$-5 = C e^{2\ln 2} + 3 \implies -5 = C(4) + 3 \implies 4C = -8 \implies C = -2$$ الحل المطلوب: $$y = -2e^{2x} + 3$$
المسألة 3 (المسألة 12 - مسألة تفاضلية هامة): مسألة شاملة 100 درجة
لتكن لدينا المعادلة التفاضلية:[span_4](start_span)[span_4](end_span) $$(E): \quad y' + 3y = \frac{9}{2} e^{-2x}$$[span_5](start_span)[span_5](end_span) والمعادلة التفاضلية المتجانسة المرافقة:[span_6](start_span)[span_6](end_span) $$(E'): \quad y' + 3y = 0$$[span_7](start_span)[span_7](end_span) ونفرض لدينا التابع $g$ المعرف على $\mathbb{R}$ وفق: $g(x) = \lambda e^{-2x}$ حيث $\lambda \in \mathbb{R}$[span_8](start_span)[span_8](end_span). والمطلوب:
  • 1) عيّن قيمة الثابت الحقيقي $\lambda$ حتى يكون التابع $g$ حلاً للمعادلة التفاضلية $(E)$.[span_9](start_span)[span_9](end_span)
  • 2) حل المعادلة التفاضلية $(E')$.[span_10](start_span)[span_10](end_span)
  • 3) أثبت أن التابع $f$ هو حل للمعادلة $(E)$ إذا وفقط إذا كان التابع $(f - g)$ حلاً للمعادلة $(E')$.[span_11](start_span)[span_11](end_span)
  • 4) استنتج جميع حلول المعادلة التفاضلية $(E)$.[span_12](start_span)[span_12](end_span)
إثبات التكافؤ بالاتجاهين + تعيين الثوابت 100 درجة

خطوات الحل التحريري بالتفصيل:

1) إيجاد $\lambda$: $g'(x) = -2\lambda e^{-2x}$.
لكي يكون $g$ حلاً لـ $(E)$[span_13](start_span)[span_13](end_span)، يجب أن يحقق: $g'(x) + 3g(x) = \frac{9}{2}e^{-2x}$.
$$-2\lambda e^{-2x} + 3(\lambda e^{-2x}) = \frac{9}{2}e^{-2x} \implies \lambda e^{-2x} = \frac{9}{2}e^{-2x} \implies \lambda = \frac{9}{2}$$ إذن: $g(x) = \frac{9}{2} e^{-2x}$.
2) حل $(E')$[span_14](start_span)[span_14](end_span): $y' = -3y \implies y = C e^{-3x}$ حيث $C \in \mathbb{R}$.
3) إثبات التكافؤ $( \iff )$:
$(\Rightarrow)$ إذا كان $f$ حلاً لـ $(E)$[span_15](start_span)[span_15](end_span) فإن $f' + 3f = \frac{9}{2}e^{-2x}$. وبما أن $g' + 3g = \frac{9}{2}e^{-2x}$، بطرح المعادلتين:
$$(f' - g') + 3(f - g) = 0 \implies (f - g)' + 3(f - g) = 0$$ أي أن $(f - g)$ حل للمعادلة $(E')$[span_16](start_span)[span_16](end_span).
$(\Leftarrow)$ بالعكس: إذا كان $(f - g)$ حلاً لـ $(E')$[span_17](start_span)[span_17](end_span)، فإن $(f - g)' + 3(f - g) = 0$. وبجمعها مع $g' + 3g = \frac{9}{2}e^{-2x}$ نجد:
$$f' + 3f = \frac{9}{2}e^{-2x}$$ وبالتالي $f$ حل لـ $(E)$[span_18](start_span)[span_18](end_span).
4) استنتاج جميع حلول $(E)$[span_19](start_span)[span_19](end_span):
$f(x) - g(x) = C e^{-3x} \implies f(x) = C e^{-3x} + \frac{9}{2} e^{-2x} \quad (C \in \mathbb{R})$.
المسألة 4 (المسألة رقم 9 في الاختبار): تعيين كثير حدود كحل خاص
عيّن تابعاً كثير حدود من الدرجة الثانية $f(x) = ax^2 + bx + c$ بحيث يكون حلاً للمعادلة التفاضلية الآتية:[span_20](start_span)[span_20](end_span)
$$-y + 2y' = x^2 + 3$$[span_21](start_span)[span_21](end_span)
اشتق التابع $f$ ثم طابق المعاملات لإيجاد $a, b, c$ 40 درجة

سلم الحل التحريري:

نفرض $y = ax^2 + bx + c \implies y' = 2ax + b$.
نعوض في المعادلة التفاضلية $-y + 2y' = x^2 + 3$[span_22](start_span)[span_22](end_span):
$$-(ax^2 + bx + c) + 2(2ax + b) = x^2 + 3$$ $$-ax^2 + (-b + 4a)x + (-c + 2b) = x^2 + 0x + 3$$
بمطابقة الأمثال:
1) $-a = 1 \implies a = -1$
2) $-b + 4a = 0 \implies -b - 4 = 0 \implies b = -4$
3) $-c + 2b = 3 \implies -c - 8 = 3 \implies c = -11$
كثير الحدود المطلوب: $$f(x) = -x^2 - 4x - 11$$

التمرين 8 (المسألة رقم 11 في الاختبار): قوى وتغيير أساس
حل في $\mathbb{R}$ كلاً من المعادلات والمتراجحات الآتية:[span_32](start_span)[span_32](end_span)

$x = 0 \implies f(0) = \frac{1}{2} \implies A\left(0, \frac{1}{2}\right)$.
