المعادلات التفاضلية ودراسة التوابع الأسية

المادة: الرياضيات (تحريري)

المدة: 3 ساعات

الدرجة: 600 درجة

أولاً: المعادلات والمتطابقات الأسية

المسألة 1:
أثبت صحة المطابقة الآتية أياً كان $x \in \mathbb{R}$:[span_0](start_span)[span_0](end_span) $$\frac{e^x - e^{-x}}{e^x + e^{-x}} = \frac{e^{2x} - 1}{e^{2x} + 1}$$[span_1](start_span)[span_1](end_span)

سلم الحل:

بضرب حدي الكسر في الطرف الأيسر بالمقدار $e^x$:[span_2](start_span)[span_2](end_span) $$\frac{e^x(e^x - e^{-x})}{e^x(e^x + e^{-x})} = \frac{e^{2x} - e^0}{e^{2x} + e^0} = \frac{e^{2x} - 1}{e^{2x} + 1}$$[span_3](start_span)[span_3](end_span) وهو المطلوب.[span_4](start_span)[span_4](end_span)
المسألة 2:
حل في المجموعة $\mathbb{R}$ المعادلة الآتية:[span_5](start_span)[span_5](end_span) $$\frac{e^x - 1}{e^x - 4} = -2$$[span_6](start_span)[span_6](end_span)

سلم الحل:

شرط الحل: $e^x - 4 \neq 0 \implies x \neq \ln 4$.
$$e^x - 1 = -2(e^x - 4) \implies e^x - 1 = -2e^x + 8 \implies 3e^x = 9 \implies e^x = 3 \implies x = \ln 3$$ مجموعة الحلول: $S = \{\ln 3\}$.
المسألة 3:
حل في $\mathbb{R}$ كلاً من:[span_7](start_span)[span_7](end_span)
  • 1) المعادلة: $2e^{2x} - 7e^x + 3 = 0$[span_8](start_span)[span_8](end_span)
  • 2) المتراجحة: $2e^{2x} - 7e^x + 3 \le 0$[span_9](start_span)[span_9](end_span)

سلم الحل:

نضع $X = e^x > 0 \implies 2X^2 - 7X + 3 = 0$.
الجذران: $X = \frac{1}{2}$ أو $X = 3$.
- $e^x = \frac{1}{2} \implies x = -\ln 2$
- $e^x = 3 \implies x = \ln 3$
حلول المعادلة: $S = \{-\ln 2, \ln 3\}$.
المتراجحة محققة بين الجذرين:
$$\frac{1}{2} \le e^x \le 3 \implies -\ln 2 \le x \le \ln 3$$ مجموعة الحلول: $S = [-\ln 2, \ln 3]$.
المسألة 4:
حل في $\mathbb{R}$ كلاً من المعادلات والمتراجحات الآتية:[span_10](start_span)[span_10](end_span)
  • 1) $49^x - 6 \times 7^x + 5 = 0$[span_11](start_span)[span_11](end_span)
  • 2) $\left(\frac{1}{3}\right)^x > 2$[span_12](start_span)[span_12](end_span)
  • 3) $5^{x+1} = 2$[span_13](start_span)[span_13](end_span)
  • 4) $2^{3x+1} = 32$[span_14](start_span)[span_14](end_span)

سلم الحل:

1) نضع $u = 7^x > 0 \implies u^2 - 6u + 5 = 0 \implies (u-1)(u-5) = 0$.
- $7^x = 1 \implies x = 0$
- $7^x = 5 \implies x = \frac{\ln 5}{\ln 7}$
2) $3^{-x} > 2 \implies -x \ln 3 > \ln 2 \implies x < -\frac{\ln 2}{\ln 3}$.
3) $(x+1)\ln 5 = \ln 2 \implies x = \frac{\ln 2}{\ln 5} - 1$.
4) $2^{3x+1} = 2^5 \implies 3x + 1 = 5 \implies x = \frac{4}{3}$.

ثانياً: المعادلات التفاضلية التحريرية

المسألة 5 (دورة 2024 الأولى):
لتكن لدينا المعادلة التفاضلية الآتية: $$(E): \quad y' - 2y = 0$$
  • 1) أوجد الحل العام للمعادلة التفاضلية $(E)$ على المجموعة $\mathbb{R}$.
  • 2) عيّن الحل الخاص $f$ للمعادلة $(E)$ الذي يحقق الشرط الابتدائي: $f(0) = 1$.
خطوات الحل التحريري مخصصة لورقة الإجابة

سلم الحل:

1) الحل العام: المعادلة من الشكل $y' = 2y$، حلها العام: $$y = C e^{2x} \quad (C \in \mathbb{R})$$
2) الحل الخاص: نعوض $f(0) = 1$: $$1 = C e^0 \implies C = 1$$ وبالتالي الحل الخاص المطلوب: $$f(x) = e^{2x}$$
المسألة 6:
حل المعادلة التفاضلية الآتية:[span_15](start_span)[span_15](end_span) $$y' - 2y = -6$$[span_16](start_span)[span_16](end_span) علماً أن الخط البياني للحل يمر بالنقطة $A(\ln 2, -5)$[span_17](start_span)[span_17](end_span).

سلم الحل:

الحل العام من الشكل $y = C e^{2x} - \frac{-6}{2} = C e^{2x} + 3$.
بالتعويض عن النقطة $A(\ln 2, -5)$[span_18](start_span)[span_18](end_span): $$-5 = C e^{2\ln 2} + 3 \implies -5 = 4C + 3 \implies 4C = -8 \implies C = -2$$ الحل هو: $$y = -2e^{2x} + 3$$
المسألة 7:
لتكن لدينا المعادلة التفاضلية:[span_19](start_span)[span_19](end_span) $$(E): \quad y' + 3y = \frac{9}{2} e^{-2x}$$[span_20](start_span)[span_20](end_span) والمعادلة التفاضلية المتجانسة المرافقة:[span_21](start_span)[span_21](end_span) $$(E'): \quad y' + 3y = 0$$[span_22](start_span)[span_22](end_span) ونفرض التابع $g$ المعرف على $\mathbb{R}$ وفق: $g(x) = \lambda e^{-2x}$ حيث $\lambda \in \mathbb{R}$[span_23](start_span)[span_23](end_span).
  • 1) عيّن قيمة الثابت الحقيقي $\lambda$ حتى يكون التابع $g$ حلاً للمعادلة التفاضلية $(E)$[span_24](start_span)[span_24](end_span).
  • 2) حل المعادلة التفاضلية $(E')$[span_25](start_span)[span_25](end_span).
  • 3) أثبت أن التابع $f$ هو حل للمعادلة $(E)$ إذا وفقط إذا كان التابع $(f - g)$ حلاً للمعادلة $(E')$[span_26](start_span)[span_26](end_span).
  • 4) استنتج جميع حلول المعادلة التفاضلية $(E)$[span_27](start_span)[span_27](end_span).

سلم الحل:

1) $g'(x) = -2\lambda e^{-2x}$. بالتعويض في $(E)$[span_28](start_span)[span_28](end_span): $$-2\lambda e^{-2x} + 3\lambda e^{-2x} = \frac{9}{2}e^{-2x} \implies \lambda = \frac{9}{2}$$ إذن: $g(x) = \frac{9}{2} e^{-2x}$.
2) حل $(E')$[span_29](start_span)[span_29](end_span): $y' = -3y \implies y = C e^{-3x} \quad (C \in \mathbb{R})$.
3) بما أن $g' + 3g = \frac{9}{2}e^{-2x}$، فإن: $$f' + 3f = \frac{9}{2}e^{-2x} \iff (f' - g') + 3(f - g) = 0 \iff (f - g)' + 3(f - g) = 0$$ أي أن $(f - g)$ حل للمعادلة $(E')$[span_30](start_span)[span_30](end_span).
4) $f(x) - g(x) = C e^{-3x} \implies f(x) = C e^{-3x} + \frac{9}{2} e^{-2x} \quad (C \in \mathbb{R})$.
المسألة 8:
عيّن تابعاً كثير حدود من الدرجة الثانية $f(x) = ax^2 + bx + c$ بحيث يكون حلاً للمعادلة التفاضلية الآتية:[span_31](start_span)[span_31](end_span) $$-y + 2y' = x^2 + 3$$[span_32](start_span)[span_32](end_span)

سلم الحل:

مشتق كثير الحدود: $y' = 2ax + b$. بالتعويض في المعادلة[span_33](start_span)[span_33](end_span): $$-(ax^2 + bx + c) + 2(2ax + b) = x^2 + 3$$ $$-ax^2 + (4a - b)x + (2b - c) = x^2 + 3$$ بمطابقة الأمثال: $$-a = 1 \implies a = -1$$ $$4(-1) - b = 0 \implies b = -4$$ $$2(-4) - c = 3 \implies -8 - c = 3 \implies c = -11$$ التابع هو: $f(x) = -x^2 - 4x - 11$.

ثالثاً: دراسة التغيرات والمماسات والمقاربات

المسألة 9:
ليكن $f$ تابعاً معرفاً على $\mathbb{R}$ وفق $f(x) = (ax + b)e^x + 1$[span_34](start_span)[span_34](end_span).
عيّن العددين الحقيقيين $a$ و $b$ إذا علمت أن الخط البياني $C_f$ يقبل في النقطة التي فاصلتها $x = 1$ مماساً أفقياً، وأن $f(0) = -e + 1$[span_35](start_span)[span_35](end_span).

سلم الحل:

المشتق: $f'(x) = (ax + a + b)e^x$.
المماس أفقي عند $x = 1 \implies f'(1) = 0 \implies 2a + b = 0 \implies b = -2a$.
من الشرط $f(0) = -e + 1 \implies b + 1 = -e + 1 \implies b = -e$.
وعليه يكون: $a = \frac{e}{2}$.
المسألة 10:
ليكن $f$ التابع المعرف على $\mathbb{R}$ وفق:[span_36](start_span)[span_36](end_span) $$f(x) = \frac{e^x}{e^x + 1}$$[span_37](start_span)[span_37](end_span)
  • 1) أوجد معادلة المماس $T$ للخط $C_f$ في نقطة تقاطعه مع محور التراتيب[span_38](start_span)[span_38](end_span).
  • 2) ادرس الوضع النسبي للخط $C_f$ والمماس $T$[span_39](start_span)[span_39](end_span).

سلم الحل:

1) $x = 0 \implies f(0) = \frac{1}{2}$، النقطة $A(0, 1/2)$.
المشتق: $f'(x) = \frac{e^x}{(e^x+1)^2} \implies f'(0) = \frac{1}{4}$.
معادلة المماس: $y - \frac{1}{2} = \frac{1}{4}(x - 0) \implies T: y = \frac{1}{4}x + \frac{1}{2}$.
2) النقطة $A(0, 1/2)$ نقطة انعطاف:
- على $]-\infty, 0[$: الخط $C_f$ يقع فوق المماس $T$.
- عند $x = 0$: الخط يشترك مع المماس ويخترقه.
- على $]0, +\infty[$: الخط $C_f$ يقع تحت المماس $T$.
المسألة 11:
ليكن $f$ تابعاً معرفاً على $\mathbb{R}$ وفق:[span_40](start_span)[span_40](end_span)[span_41](start_span)[span_41](end_span) $$f(x) = x + 3 + \frac{x-1}{4e^x}$$[span_42](start_span)[span_42](end_span)[span_43](start_span)[span_43](end_span) أثبت أن المستقيم $\Delta: y = x + 3$ مقارب مائل للخط البياني $C_f$ في جوار $+\infty$، ثم ادرس الوضع النسبي لـ $C_f$ والمقارب $\Delta$[span_44](start_span)[span_44](end_span)[span_45](start_span)[span_45](end_span).

سلم الحل:

$$\lim_{x \to +\infty} [f(x) - (x + 3)] = \lim_{x \to +\infty} \frac{x - 1}{4e^x} = 0$$ المستقيم $\Delta$ مقارب مائل في جوار $+\infty$.[span_46](start_span)[span_46](end_span)[span_47](start_span)[span_47](end_span)
الوضع النسبي من إشارة $(x - 1)$:[span_48](start_span)[span_48](end_span)[span_49](start_span)[span_49](end_span)
- إذا كان $x \in ]-\infty, 1[$: الخط $C_f$ يقع تحت $\Delta$.
- إذا كان $x = 1$: الخط $C_f$ يقطع $\Delta$ في النقطة $(1, 4)$.
- إذا كان $x \in ]1, +\infty[$: الخط $C_f$ يقع فوق $\Delta$.
المسألة 12:
ليكن $f$ التابع المعرف على $\mathbb{R}$ وفق: $f(x) = \ln(e^x + 1)$[span_50](start_span)[span_50](end_span)[span_51](start_span)[span_51](end_span).
  • 1) احسب $\lim_{x \to -\infty} f(x)$ وفسّر النتيجة هندسياً[span_52](start_span)[span_52](end_span)[span_53](start_span)[span_53](end_span).
  • 2) أثبت أنه أياً كان $x \in \mathbb{R}$ فإن $f(x) = x + \ln(1 + e^{-x})$[span_54](start_span)[span_54](end_span)[span_55](start_span)[span_55](end_span).
  • 3) استنتج معادلة مقارب مائل $\Delta$ لـ $C_f$ في جوار $+\infty$ وادرس الوضع النسبي بينهما[span_56](start_span)[span_56](end_span)[span_57](start_span)[span_57](end_span).
  • 4) ادرس تغيرات التابع $f$ ونظم جدولاً بها[span_58](start_span)[span_58](end_span)[span_59](start_span)[span_59](end_span).

سلم الحل:

1) $\lim_{x \to -\infty} \ln(e^x + 1) = \ln(1) = 0$. المستقيم $y = 0$ مقارب أفقي بجوار $-\infty$.
2) $f(x) = \ln[e^x(1 + e^{-x})] = \ln(e^x) + \ln(1 + e^{-x}) = x + \ln(1 + e^{-x})$.
3) $\lim_{x \to +\infty} [f(x) - x] = \lim_{x \to +\infty} \ln(1 + e^{-x}) = 0 \implies \Delta: y = x$ مقارب مائل بجوار $+\infty$.
بما أن $1 + e^{-x} > 1$ فإن الفرق موجباً دوماً والخط $C_f$ يقع تماماً فوق $\Delta$.
4) $f'(x) = \frac{e^x}{e^x + 1} > 0$، التابع متزايد تماماً على $\mathbb{R}$.
المسألة 13:
ليكن التابع $f$ معرفاً على $\mathbb{R}$ وفق:[span_60](start_span)[span_60](end_span) $$f(x) = \frac{1}{2}(e^x - e^{-x})$$[span_61](start_span)[span_61](end_span)
  • 1) أثبت أن التابع $f$ فردي[span_62](start_span)[span_62](end_span).
  • 2) ادرس تغيرات التابع $f$ ونظم جدولاً بها[span_63](start_span)[span_63](end_span).
  • 3) أثبت أنه أياً كان $m \in \mathbb{R}$، فإن للمعادلة $f(x) = m$ حلاً وحيداً يُعطى بالصيغة:[span_64](start_span)[span_64](end_span) $$x = \ln(m + \sqrt{m^2 + 1})$$[span_65](start_span)[span_65](end_span)
  • 4) اكتب معادلة المماس $T$ في المبدأ $O(0,0)$[span_66](start_span)[span_66](end_span).

سلم الحل:

1) $f(-x) = \frac{1}{2}(e^{-x} - e^x) = -f(x)$ فالتابع فردي.
2) $f'(x) = \frac{1}{2}(e^x + e^{-x}) > 0$، متزايد تماماً على $\mathbb{R}$ من $-\infty$ إلى $+\infty$.
3) $\frac{1}{2}(e^x - e^{-x}) = m \implies (e^x)^2 - 2m(e^x) - 1 = 0$.
المميز $\Delta' = m^2 + 1 > 0$. الحل الموجب المقبول: $$e^x = m + \sqrt{m^2 + 1} \implies x = \ln(m + \sqrt{m^2 + 1})$$[span_67](start_span)[span_67](end_span)
4) $f'(0) = 1 \implies T: y = x$.
المسألة 14:
ليكن $f$ التابع المعرف على $\mathbb{R}$ وفق:[span_68](start_span)[span_68](end_span) $$f(x) = \frac{(x+1)^2}{e^x}$$[span_69](start_span)[span_69](end_span)
  • 1) احسب نهايات التابع عند أطراف مجموعة التعريف، وفسر النتيجة عند $+\infty$ هندسياً[span_70](start_span)[span_70](end_span).
  • 2) أثبت أنه أياً كانت $x \in \mathbb{R}$ فإن مشتق التابع يُعطى بالعلاقة:[span_71](start_span)[span_71](end_span) $$f'(x) = \frac{1 - x^2}{e^x}$$[span_72](start_span)[span_72](end_span)
  • 3) ادرس تغيرات التابع $f$ ونظم جدولاً بها، ودلّ على القيم الحدية ونوعها[span_73](start_span)[span_73](end_span).

سلم الحل:

1) $\lim_{x \to -\infty} f(x) = +\infty$، و $\lim_{x \to +\infty} f(x) = 0$. المستقيم $y = 0$ مقارب أفقي بجوار $+\infty$.
2) $f'(x) = \frac{2(x+1)e^x - (x+1)^2 e^x}{e^{2x}} = \frac{(x+1)(2 - x - 1)}{e^x} = \frac{1 - x^2}{e^x}$.[span_74](start_span)[span_74](end_span)
3) إشارة المشتق توافق إشارة $1 - x^2$:
- عند $x = -1$: $f(-1) = 0$ قيمة صغرى محلية.
- عند $x = 1$: $f(1) = \frac{4}{e}$ قيمة كبرى محلية.
